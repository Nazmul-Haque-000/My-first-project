# My First Project

This is my first project using Git and GitHub, created and managed using Git Bash.

## 📌 Description
This project is a basic static webpage built using HTML and CSS.  
It was created as a practice project to learn how to:
- Use Git for version control
- Work with GitHub repositories
- Structure a simple web project

## 🛠️ Technologies Used
- HTML
- CSS
- Git
- Git Bash

## 📂 Project Structure
- `index.html` → Main webpage structure
- `style.css` → Styling for the webpage

## 🚀 How to Run
1. Clone the repository:
2. Open the project folder
3. Open `index.html` in your browser

## 🎯 Purpose
The purpose of this project is to practice:
- Basic web development
- Git commands (add, commit, push)
- Uploading projects to GitHub
